# Mythfits website asset starter pack

Reconstructed from the approved hybrid phoenix brand board using image generation. These are standalone reinterpretations, not pixel-identical extractions from editable source layers.

## Files
- hero/phoenix-hero-desktop.png: wide text-free artwork; keep phoenix on right and HTML text on left. Mobile should use a separate image block with object-position:right, rather than placing text over a tight crop.
- brand/phoenix-emblem.png: transparent raster emblem, dark feather version.
- brand/logo-light-background.png: transparent horizontal logo for light backgrounds.
- brand/logo-dark-background-stacked.png: transparent stacked logo for dark backgrounds. This reconstruction is stacked rather than horizontal.
- icons/*.svg: crisp independently reconstructed vector process icons.

## Implementation
Keep all headings, descriptions, navigation and buttons as real HTML. Use decorative empty alt text for hero if adjacent copy carries its meaning; logo alt text: Mythfits.
Suggested starting palette: charcoal #181818, warm ivory #FFF5E6, ember #E65A16, copper #B76A35. These are implementation approximations, not sampled print standards.

## Production status
PNG assets include alpha transparency, but the generated emblem contains soft translucent glow. Logo reconstructions differ slightly in details across variants. Before a final brand release, select one canonical phoenix drawing and create consistent clean SVG logo masters and a simplified favicon. These PNGs are suitable starting artwork, not certified print masters. SVG process icons are true vectors; phoenix PNGs are raster, not SVG files.
